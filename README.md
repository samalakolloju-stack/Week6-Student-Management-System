
# Student Management System

## Project Description
The Student Management System is a Python-based application that helps users manage student records. Users can add, view, search, update, and delete student details. The records are saved in a JSON file.

## Features
- Add new student records
- View all students
- Search for a student by ID
- Update student details
- Delete student records
- Save data between program runs
- Handle invalid input

## Installation / Setup
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the program using the command below.

## How to Run
```bash
python main.py
```

## Data Storage
Student information is stored in `students.json`, which is created when records are saved.
